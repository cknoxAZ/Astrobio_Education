# Teaching Astrobiology — multipage website

Upload every file in this folder to the root of your existing GitHub repository. Replace index.html and README.md, and add all seven new HTML pages. Keep all HTML files together at the same level. Commit changes; GitHub Pages will redeploy using your existing settings.

## Pages

- index.html — teaching approaches, 5 Ps, activities, resources
- big-questions.html — overview of the six big questions
- origins.html — How does life begin?
- habitability.html — Where could life exist?
- recognizing-life.html — How would we recognize life?
- survival.html — How does life survive and change?
- exoplanets.html — Are there habitable worlds beyond our solar system?
- meaning.html — What would finding life mean?

No build step, dependencies, or installation required. Open index.html locally to preview. Navigation uses relative paths for GitHub project sites. The native dropdown supports keyboard and touch; Escape closes it.

Each topic includes basics, evidence and uncertainty, a UA research connection, mission context, classroom and place connections, humanities/ethics, and source links. Research and mission information was reviewed October 17, 2026. Check source pages before teaching; status information is not updated automatically. Activities are original sketches, not complete lesson plans or formal standards alignments.

Existing resource search, activity tabs, and downloadable planning notes remain on the homepage. Notes are not transmitted or retained after leaving the page.

Validation: JavaScript syntax, unique IDs, relative links, fragment targets, and archive integrity checked. Visual browser testing has not been completed. No license is assigned; choose one before inviting reuse.
