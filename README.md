# Teaching Astrobiology

A responsive, self-contained educational webpage connecting astrobiology with place-based education, interdisciplinary inquiry, humanities and ethics, active learning, and the LINCSS 5 Ps.

## Files

- `index.html` — complete webpage, styles, illustration, and interactions.
- `.nojekyll` — serves the webpage directly on GitHub Pages.
- `.gitignore` — excludes common local and sensitive files.

No dependencies, installation, or build step are required.

## Upload to GitHub

1. Extract this ZIP on your computer.
2. Create a GitHub repository, for example `teaching-astrobiology`.
3. In the repository, choose **Add file → Upload files**.
4. Upload the files **inside** the extracted folder so `index.html` is at the repository root. Do not upload the ZIP itself. Include `.nojekyll` and `.gitignore` if your file picker displays them.
5. Commit the files.

## Publish with GitHub Pages

1. Open the repository’s **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select `main` and `/(root)`, then save.
4. GitHub displays the website address when deployment completes.

GitHub Pages availability depends on your account and repository visibility. A public repository makes its source visible; publishing with Pages does not preserve the original ChatGPT Site’s private access controls.

## Edit or preview

Open `index.html` in a browser. Edit it with any text editor and refresh to see changes. Resource entries and sample lessons are in the `resources` and `lessons` arrays near the end of the file.

## Included interactions

- Keyboard-accessible activity tabs
- Resource search and topic filtering
- Downloadable lesson-planning notes
- Responsive layouts and print styles

Planning notes are not sent to a server or retained after leaving the page. Download them to keep a copy.

## Content notes

The activity sketches are original teaching examples, not complete lesson plans or formal standards alignments. External resources link to NASA and the Lunar and Planetary Institute. Review external links and adapt activities to learner needs and local procedures before use. No license is assigned by this package; choose an appropriate license before inviting reuse.

JavaScript syntax and internal navigation targets were checked. Visual browser testing has not been completed.
